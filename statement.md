# Project Statement

## Problem Statement
Small lending institutions and financial analysts often struggle to quickly evaluate individual loan applicants using multiple financial metrics. Manual evaluations are slow, inconsistent, and prone to human error when calculating risk exposure across income, credit limits, and delinquency histories.

## Scope of Project
This project provides an automated Python application that takes applicant financial data, calculates key indicators (Debt-to-Income ratio and Credit Utilization rate), and assigns a composite financial risk score from 0 to 100 with categorical tiers (Low, Moderate, High Risk).

## Target Users
- Individual credit evaluators and loan officers
- Personal finance students and financial analysts
- Small-scale peer-to-peer lending managers

## High-Level Features
- Input validation to catch invalid financial parameters
- Automated credit risk scoring engine based on weighted business logic
- Data persistence using JSON file storage
- Metric visualization using Matplotlib bar charts
